## Fresh checks for this review

- All 39 entries in the attachment's CONTENTS-SHA256.txt matched their files.
- All 33 portable release-manifest entries matched recorded size and SHA256; the executable reports 1.11.2+31.
- The installer matched its supplied build hash. Installer and app do not carry an Authenticode publisher signature.
- The attachment contained an expanded Portable folder, not the portable ZIP named in BUILD-SHA256.txt. A new ZIP was made from the exact folder. Every archived file and its content were compared with the supplied payload. The new checksum list applies to this recreated ZIP.
- The supplied source ZIP was retained unchanged. A preliminary scan found no personal credentials, private signing keys, downloaded games, databases or compiler caches.
- A local windows-stable.json was signed with the existing publisher key. Its public-key fingerprint matches the supplied binary's BUILD-INFO. Public-key signature verification and altered-payload rejection passed. Its URLs point to the planned v1.11.2 assets; these URLs are not public downloads yet.
- Current previews render the production 1.11.2 Windows widgets with sample catalog data and empty accounts/queue. No user database, account or game file was used for rendering. They are not live signed-in screenshots.
