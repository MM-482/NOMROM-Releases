## What the regressions establish

- A partial copy that throws and a completed copy with the wrong length both leave an existing destination unchanged and keep the torrent source available for retry. A valid staged copy still replaces the destination successfully.
- Pause, cancel and disposal during a blocked destination lookup prevent late file publication and completion. Pause/cancel during staged copying, delayed runtime failure shutdown and completion database writes retain the final user intent. Immediate pause/resume cannot let an old run remove or complete a newer run.
- Reuse/extraction of an existing archive respects pause/cancel. Extraction cleanup is awaited before checking for leftover staging content. A startup error cannot continue the same run into adding a torrent.
- Both HTTP and native torrent routes reject unrelated same-stem documents/folders as evidence of extraction. A successful real service extraction creates a receipt that allows reuse without another HTTP request. Changed game identity, missing/replaced/truncated output, traversal and receipt metadata collisions are rejected while existing content is preserved.

## Test environment

The tests ran on Windows x64 with the pinned Flutter 3.47.7 SDK. The initial standard command was blocked before tests by a Windows compiler-path quoting problem in `native_toolchain_c` 0.19.2. An isolated copy of that build-tool package changed its Windows process launch to avoid the shell for native executables; only generated local package configuration pointed to the copy. The checked-in dependency lock and shared installed package cache were unchanged. With that local tooling correction, the official Flutter runner compiled the SQLite native dependency and executed both the focused and full suites normally. The [exact local tool patch](v1.11.3-build-tool-workaround.patch) is included for reproducibility; this is not a claim that the unmodified build workflow passed on this host.

Early exploratory in-process runner results are not substituted for the fresh official-runner totals above. Preview tooling and compiled test output are excluded from the distributable source archive.
